# System Glossary

## Topology

The physical structure of the transit network.

## Event

An immutable record of something that occurred.

## Snapshot

A reconstruction of system state at a point in time.

## Projection

A derived view generated from events.

## Vehicle Journey

A vehicle's traversal through the network.

## Reachability

Whether a destination can be reached from a source.

## Transfer

Movement between services, routes, platforms, or stations.

## Event Time

When an occurrence actually happened.

## Processing Time

When the system observed the occurrence.

## Snapshot Time

When a state reconstruction was generated.
